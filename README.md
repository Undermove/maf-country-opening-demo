# maf-country-opening-demo

Демо-репозиторий для доклада про **Microsoft Agent Framework (MAF)**.

Имитирует внутренний процесс **открытия новой страны** в Dodo: в репозитории лежат
конфиги уже открытых стран и список языков. Во время демо агент на MAF:

1. создаёт ветку `feature/country-<код>`;
2. добавляет конфиг новой страны `countries/<код>.json`;
3. открывает **настоящий Pull Request** — но только после подтверждения человеком.

Тулы агента жёстко ограничены: он может создать ветку, добавить файл страны и открыть PR
**только в этом репозитории** — и ничего больше. В этом и суть: ИИ ходит в вашу бизнес-логику
ровно там, где вы разрешили.
